# System overview

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

The larger Delivery UAV is an F450-family quadrotor with Pixhawk, GPS/compass, RC receiver, telemetry and a physical servo release. The smaller Scout UAV is a carbon-frame quadrotor with GHF411 PRO-BMI-family AIO and Gremlin motors. Historic Drone A/B names vary and are avoided.

Manual FPV scouting and the delivery-controller workflow are documented. Author-reported YOLO/LiDAR work is retained as development history; no executable deployed detector or autonomous coordination protocol is recovered. The actuator command interface is an unverified boundary.

Start with [system layout](../drawings/system_layout.svg), [photo map](Photo_Map.md), [mechanical BOM](../bom/mechanical_bom.csv) and [evidence ledger](../data/evidence_ledger.csv). New R01 geometry is a bench reference and cannot substitute for historical design evidence.
