# Provenance and rights

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

All 49 source paths and SHA-256 values are in [the source manifest](../data/source_manifest.csv). Included originals and metadata treatment are in [the asset register](../data/included_original_assets.csv). The image inventory separates project photographs from vendor graphics.

The five STEP sources were privately inspected only; see [exclusion rationale](EXCLUDED_THIRD_PARTY_CAD.md). R01 is a new topology constructed from explicit independent dimensions without importing source shapes. Functional diagrams are not traced restricted CAD.

The authors approve publication of their own records. Both authors approved open licences on 21 October 2026 (CERN-OHL-W-2.0, MIT, CC-BY-4.0); see [licences](../LICENSES.md). A new repository URL or DOI must be added only after it exists.
