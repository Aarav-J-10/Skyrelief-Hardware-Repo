# Manufacturing and safety

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

No historical fabrication-ready drawing set is recovered. Restricted source CAD is excluded. R01 has no assigned material or manufacturing process. Before fabrication an engineer must specify material, orientation, fits, fastening, edge finish and inspection criteria. Nominal hole diameters are not process allowances.

For later bench work, isolate stored energy, remove propellers, restrain the mechanism and protect the drop zone with a dummy payload. Keep fingers outside moving paths. Review jam, unintended-release, power-loss and residual-retention hazards. The historical safety prose is not evidence those checks passed.

No torque, working load, aerodynamic load, battery-restraint strength or flight certification is specified. Solid validity cannot supply these values. Complete aircraft qualification also requires propulsion, thermal, vibration, EMI and failsafe review; the 19/20 retrospective assertion does not replace it.
