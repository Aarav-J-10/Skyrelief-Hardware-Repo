# Assumptions and unknowns

**Historical SkyRelief hardware dossier with modern engineering reconstruction.** Source-supported components and connectivity are distinguished from new reference implementations. Unrecovered pin assignments, firmware parameters and code must not be treated as as-built records or electrically validated flight instructions.

Installed frame revision/material, joint schedule, latch dimensions, linkage, servo horn, travel, stops and loads are unrecovered. The photographed bracket is not equated with D05. R01 dimensions are independent choices with no historical fit claim.

The parameter JSON records the new design table, units and unsupported physical properties. The builder's checked topology accepts its declared design; changing unsupported geometry requires source editing and renewed validation. It is not a universal parametric aircraft generator.

Sensor mounting extrinsics, ranging coverage, vibration measurements and per-trial release outcomes remain absent. See the completed [issue matrix](../Known_Limitations.md). Unknowns are finished audit findings, not silently completed fields.
